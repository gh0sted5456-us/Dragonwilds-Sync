# Supplied visual assets

Date received: 2026-08-15

Project owner Luke supplied the following assets for Dragonwilds Sync V1.1.5:

- `renderer/assets/theme/dark-mode.webp` — Dark application theme artwork.
- `renderer/assets/theme/light-mode.webp` — Light application theme artwork.
- `renderer/assets/theme/application-backsplash.webp` — Launcher entry/loading and in-game administration-menu backsplash.
- `renderer/assets/enemies/*.webp` — 122 curated enemy, creature, NPC, prototype, and fallback icons for the launcher catalogue.
- `game-bridge/resources/application-backsplash.png` and `game-bridge/resources/enemies/*.png` — Game Bridge package copies of the shared backdrop and curated icon set.

These files are project-supplied artwork, not recovered from the original LootMenu DLL. Their inclusion does not change the provenance or redistribution restrictions documented for LootMenu.

Enemy icons are matched to reflected/catalogued game records by normalized class, runtime-path, spawn-argument, or display-name identifiers. Unknown entries retain a generated initials fallback; artwork does not determine whether an actor is safe or spawnable.
