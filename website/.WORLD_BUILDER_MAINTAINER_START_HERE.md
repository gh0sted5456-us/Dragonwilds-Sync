## Mandatory compatibility instruction

Do not create a second incompatible World Builder schema.

The browser produces an **untrusted Website Draft `.rsdwl`**. The desktop application validates it through a dedicated restricted import path, creates a new local World profile and fresh secrets, stages any included World save safely, and leaves the World stopped until the user explicitly launches it.

Rules and Mods are shared structured World metadata:

```text
community_rule_profile
community_rules (legacy compatibility projection)
mod_groups.ue4ss
mod_groups.runeschema
mod_groups.paks
```

Desktop, WebGUI, public descriptors, website placards, focused placards, and `.rsdwl` import/export must converge on those normalized fields rather than maintaining separate copies.
