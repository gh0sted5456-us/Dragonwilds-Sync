Dragonwilds Sync World Builder

Build the World profile
in your browser.

Define the World identity, release channel, platforms, community rules, mod families, placard artwork, and optional World-save payload before you ever start the dedicated server. Everything is assembled locally in your browser.

No account requiredArtwork stays localWorld save stays localExports .rsdwl browser draft
Browser draft security

The website creates configuration, not server authority.

A browser-generated `.rsdwl` is marked as a Website Draft. Dragonwilds Sync must validate it, create a new local World profile, generate fresh server/sync credentials locally, and safely stage any included save before the World can be launched.
