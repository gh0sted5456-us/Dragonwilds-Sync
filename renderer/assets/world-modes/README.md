# Dragonwilds World-mode icons

These compact placard assets are sourced from the public
[`RSDWArchive/RSDWTools`](https://github.com/RSDWArchive/RSDWTools) game-icon
catalog. They are packaged as optimized WebP assets so the launcher presents the same
Normal, Hardcore, Creative, and PvP symbols used by the RSDW ecosystem.

- `normal.webp`: `T_Icon_Mode_Standard.png`
- `hardcore.webp`: `T_Icon_Mode_Hardcore.png`
- `creative.webp`: `T_Icon_Mode_Creative.png`
- `pvp.webp`: `T_Icon_PVP_Enabled.png`
