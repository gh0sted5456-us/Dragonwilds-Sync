# Dragonwilds Sync V1 — Final QA, 15 August 2026

The final renderer, backend, integration, security, platform, World browser, WebHost, RSDW save/editor, profile-switching, and build-contract matrix passed. The Windows installer and portable application were built successfully after repairing an incomplete local dependency cache with the pinned lockfile.

## Real-machine acceptance

- SteamCMD installed dedicated-server build `24574222` at `C:\DragonwildsServer`.
- UE4SS, RuneSchema, the Sync PlayerTracker, and dedicated configuration were installed and detected.
- The server launched from Dragonwilds Sync, published a fingerprint manifest, answered its local status endpoint with HTTP 200, created and started its EOS session, and emitted approximately 30-second heartbeats.
- Scoped Windows firewall rules were created for Dragonwilds, Sync, and WebHost ports. The optional broad executable exception was intentionally not accepted.
- A real character save edit was written and read back through the RSDW path, then restored byte-for-byte from the automatic backup. Clone and recoverable deletion also passed.
- Real `%APPDATA%\DragonwildsSync` profile separation and persistence were confirmed. Automated isolated acceptance covers private World and dedicated-server A/B/A activation and file restoration.

## Boundaries

The public address was detected and the EOS session advertised, but a same-LAN request to that public address was refused. Router forwarding/NAT loopback therefore remains unverified and cannot be promised by the launcher without router or UPnP support.

Linux source, AppImage/tar targets, Flatpak metadata, and CI are included. A Linux binary was not generated on this Windows host because it does not have Bash/WSL. Windows packages are not Authenticode-signed because no publisher certificate was configured.

The timestamped OneDrive package contains the successful build log, 26 Help screenshots, capabilities and guides, raw source, and SHA-256 hashes. No saves, credentials, server keys, owner identifiers, or public addresses are included.
