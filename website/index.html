WebHost / WebGUI

Your server authority,
available remotely.

The WebGUI is not a second server manager. It routes supported actions through the same authoritative runtime and update controller used by the desktop application.

Authenticated sessionsCSRF protectedPermission checksAudit records

Remote Server Manager

Enter the WebGUI address configured for your server. Dragonwilds Sync checks that endpoint first, then opens that server's own login page in a new tab. The website never stores or sends your administrator credentials.

Enter a hostname/IP and WebGUI port. HTTPS is recommended for remote access.
