# Dragonwilds Sync

A definitive server launcher and peer‑to‑peer (P2P) mod synchronization tool for the *Dragonwilds* game. This repository contains the core launcher, networking utilities, and scripts to keep client mods in sync across multiple machines.

## Features
- Server launch – Easily start a dedicated Dragonwilds server with pre‑configured settings.
- Mod sync – Automatically share mod files via P2P, ensuring all players have the same versions without manual downloads.
- Python + Node.js – Core logic is written in Python; auxiliary scripts and packaging use Node.js tools.
- Cross‑platform – Works on Windows, macOS, and Linux.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/gh0sted5456-us/Dragonwilds-Sync.git
   cd Dragonwilds-Sync
   ```
2. Install dependencies (Python 3.x required):
   ```bash
   pip install -r requirements.txt
   ```
3. Run the launcher:
   ```bash
   python launch_server.py
   ```
